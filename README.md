## 📖 À propos

Ce portfolio est un projet personnel conçu pour présenter mon parcours, mes compétences et les projets sur lesquels je travaille.

L'objectif est de proposer une interface moderne, fluide et responsive, tout en mettant en avant mes compétences en développement front-end et mon intérêt pour la création d'expériences utilisateur soignées.
